# 安卓版本的边界

当前客户端由 Kotlin / Jetpack Compose 和同进程 Go 网关组成。UI 经 `Mobile.admin()` 调用 `zenbridge`，请求进入网关真实管理路由；管理 API 的 loopback 与 Origin 校验没有为 UI 放宽。

其他 AI 客户端通过手机本机的 `/v1` 接口连接网关，UI 负责交付地址与专属 Key。数字、额度、模型可用性和错误消息以网关返回为准。

前台服务负责网关生命周期、启动失败反馈和超时处理。Android 的后台、电池与前台服务限制仍然适用；不能承诺锁屏后无限期运行。

安卓版禁用桌面托盘、自更新和桌面侧配置注入。配置导入导出走系统文件选择器；第三方登录可以临时打开网页，但当前主界面是原生 Compose。

模型列表用来源与模型 ID 区分同名行；自建供应商的探测结论持久化，并按来源选择探测对象。渠道是否可用最终由账号权限、上游响应和真实调用决定。

## 首个公开预览的验证范围

从现有安卓工程整理，原生 debug/release APK 构建成功，签名及 APK 对齐检查通过。在 2311DRK48C 上完成新图标覆盖安装、冷启动和系统图标显示检查，覆盖安装前后配置文件哈希一致。

这些检查不等同于对全部第三方登录流程、长期后台存活或所有供应商模型的完整验收。后续修复和安卓发布在本仓库跟踪。
